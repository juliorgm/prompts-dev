# Testes de ViewModel

**Onde:** Copilot.
**Uso:** criar testes unitários de um ViewModel com Coroutines/Flow.
**Troque:** `{{vm}}` = #file do ViewModel.

## Parte 1 — Cenários
```
Liste os cenários de teste de {{vm}}: estado inicial, sucesso, cada erro, vazio, loading, eventos únicos e chamadas repetidas. Não escreva código ainda.
```

## Parte 2 — Código
```
Escreva a classe de teste seguindo o padrão de testes que já existe no projeto (procure um exemplo).
Use MainDispatcherRule, runTest e Turbine para os Flows. Prefira fakes a mocks quando simples. Nomes com backticks no formato "quando X, então Y".
```
